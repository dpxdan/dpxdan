Mais de 10 anos construindo sistemas de comunicação em tempo real — principalmente onde a pilha é FreeSWITCH, o debug é Wireshark e o problema chega fora do horário comercial.

Trabalho com foco em SBC, PBX multi-tenant, roteamento SIP, CDRs e automação de infraestrutura em Debian. Código pronto para produção, sem dependência de frameworks pesados onde não fazem sentido.

Atualmente no desenvolvimento do **FluxSBC**: um Session Border Controller baseado em FreeSWITCH com roteamento SIP inteligente, módulos de segurança, co-billing e interface web em PHP/CodeIgniter 2.

---

## Em andamento

- **FluxSBC** — roteamento SIP, Event Guard (bloqueio progressivo de IPs), módulo de co-billing com NFCom, migração SipPulse → FluxSBC
- **RMS** — gerenciamento de recursos de mídia e offload
- Suporte a Debian 12, migração para MySQL 8.0.x e modernização de ambientes legados
