## Sobre mim

Sou Desenvolvedor Backend com mais de 10 anos de experiência no mercado de Telecomunicações, atuando no desenvolvimento de soluções VoIP, plataformas PBX, Session Border Controllers, roteamento SIP e automações para ambientes Linux.

Meu foco principal é construir sistemas estáveis, seguros e escaláveis para comunicação em tempo real, integrando tecnologias como FreeSWITCH, SIP, RTP, WebRTC, PHP, Lua, Bash e bancos de dados relacionais.

Atualmente trabalho no desenvolvimento do FluxSBC, um Session Border Controller baseado em FreeSWITCH, com módulos personalizados para roteamento SIP, controle de chamadas, segurança, CDRs e gestão web.
